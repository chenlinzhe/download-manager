模型设置

AI 说明与智能搜索的语义扩展都由 DeepSeek 提供，仅作整理参考；未配置 Key 时表格显示「--」，其余功能不受影响。

Key 只存本机用户环境变量 DEEPSEEK_API_KEY，不写进任何配置文件、不进 Git。

忽略名单

名单里的项目名称在扫描时会被跳过（不删除任何文件）。想让它重新出现就点「恢复」，再点工具栏的「重新扫描」。

外观与主题

右上角的 ☾ / ☀ 按钮可以在深浅色之间快速切换；这里可以选「跟随系统」，让程序跟着 Windows 的浅色 / 深色设置走。

转移到其他目录

选好目标文件夹后点「开始转移」。同名目标不会覆盖；成功转移的项目会从列表里移除。
