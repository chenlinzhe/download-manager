功能说明

按平时使用的顺序，把软件里的每个功能都过一遍。软件只读文件信息，不会运行任何安装包。

一、扫描：它是怎么找到下载包的

  • 自动找下载目录：逐个磁盘（C 到 Z）看根目录下名字像下载目录的文件夹，例如 Downloads、下载、Down。
  • 手动加目录：工具栏的目录下拉里选「＋ 新增目录（可多选）…」，可以把任意文件夹加进来（含移动硬盘、网络路径、NAS 共享目录）；选的时候按住 Ctrl 或 Shift 可以一次选好几个文件夹，一次全加进来。加过之后每次扫描都会带上。
  • 只展开一层：下载目录里的项目直接列出；若某个文件夹被判定为「多个独立下载包的集合目录」，会把它里面的子项单独列成一行，显示为「集合名 / 子项名」。再深一层不展开，避免把安装目录里的 dll 也当成下载包。判断默认只用本地规则（同一层里有多个安装包、或明显是安装目录），拿不准的目录先当成一个整体；想让 AI 帮忙判断，勾设置里的「扫描时用 AI 判断目录是否该展开」。
  • 扫描为什么这么快：本地只读文件名 / 大小 / 时间，而且统计大小和文件数时会跳过 node_modules、.git、venv、__pycache__ 这类依赖与缓存目录（只按一个目录算，不进去逐个文件数）——它们动辄几十万个文件，是扫描慢的主要原因。
  • 一周复用一次结果：同一份扫描结果 7 天内直接复用，所以再次打开软件几乎立刻出列表。但一旦目录清单有变化（新增或删掉目录、新建或改名标签），下次加载会自动重扫，不会把旧列表当成新结果。想马上看最新的，随时点「重新扫描」。
  • 重新扫描：忽略缓存，重新读取每个项目的文件数、大小、修改时间、目录里是否带注册机、压缩包里有哪些文件。全程纯本地、不联网；如果上一次扫描还没跑完，再点会等它跑完再扫一遍，不会拿旧结果糊弄你。
  • 散落的图片 / 视频 / 音乐：单个媒体文件不算下载包，不列出来；主要由媒体组成的文件夹标成「媒体目录」，直接给「建议保留」。
  • 忽略名单：名单里的名字（或路径）在扫描阶段就被跳过，不删除任何文件。
  • 扫描进度：顶部状态会显示「正在枚举扫描目录 / 统计目录内容 / 保存扫描结果」，表格上方还有一行进度；读不到的目录会汇总成「N 处读取失败」，鼠标悬停看详情。

二、资源标签：第一个是「下载包」，其余自己建

  • 标签条在哪：提示条下面那一排圆角标签。第一个标签固定叫「下载包」，后面写着它下面有几个项目。
  • 「下载包」里是什么：自动发现的下载目录（各磁盘上名字含 download / 下载 的文件夹），加上你在目录下拉里手工添加的目录。
  • 新建自己的标签：点标签条右边的「＋ 新建标签」，输入名字（最多 12 字），比如「我的项目」，回车就建好，页面会自动切到这个新标签。
  • 每个标签的目录自己加：切到某个标签后，在工具栏的目录下拉里选「＋ 新增目录（可多选）…」，选中的目录就加到这个标签下面（一次可以选好几个）；第一个标签「下载包」加目录的方式跟以前一样。一个目录只归一个标签，重复选会自动跳过。
  • 功能完全一样：每个标签都能扫描、看顶部四张卡片、按目录筛选、智能搜索、AI 分析、标为保留 / 忽略 / 转移 / 移到回收站、改这一格的说明，用法一模一样，区别只是看的是这一组目录。
  • 改名或切走：除「下载包」外，标签右侧的 ✎ 可以改名（Enter 保存、Esc 放弃）；点标签本身就切换视图，四张卡片和表格都只算当前标签里的项目。
  • 标签只换视角：新建 / 改名标签不会动任何文件，也不改变清理建议的算法；想让某个项目彻底不参与清理，就勾上再「标为保留」或右键「忽略」。标签存在本机 resource_groups.json。

三、顶部四张卡片

  • 扫描到的项目：当前列表里的项目数。
  • 总占用：所有项目的体积之和（文件夹按内部所有文件累计）。
  • 建议不用保住：判为「不用保住」的数量，也就是优先清理的候选。
  • 疑似激活 / 破解风险：目录里出现注册机、Keygen、破解补丁之类文件的项目数量。

四、表格每一列

  • 勾选框：勾上后才能用右侧按钮批量操作；表头那个勾是全选 / 全不选。
  • 包 / 路径：名称、所在目录（点一下直接在资源管理器里打开）、类型和文件数；本次扫描新出现的项目带「新增」徽章。
  • AI 说明：这是个什么包：一句话说明，AI 说的前面标「AI：」，后面用小字标「多久前分析的」。说得不准就双击这一格改（键盘 Tab 走到这里按 Enter 也行）：框里那句「AI：…」是素材——留着保存＝接受它，保存时并入你的话；删掉＝不要那部分；全删干净＝这一格空着、AI 不再写回来。你动过之后这一格只显示你的内容，不再单独出现「AI：」。
  • 建议：保留（手工）／建议保留／待确认／不用保住。手工保留的徽章旁带一个小 ✕，点它就能取消保留。
  • 价值分：0 到 100 的留用价值，越低越该清理（38 分以下为「不用保住」，65 分以上为「建议保留」）。
  • 大小、时间：体积与最近修改日期，下面小字是「多少天前」。
  • 可重下性：方便（建议官网）／可重下，但可能需账户或授权／不确定／不确定或可能无法重下。
  • 注册 / 授权情况：是否发现注册机、是否商业软件、是否需要账户或许可证；有风险时这一列变红提示。
  • 判断依据：这条建议是怎么算出来的（年龄、体积、是否公开软件、是否疑似破解、是否来自集合目录等）。
  • 排序：点带箭头的表头按该列升 / 降序，再点一次反向；清空间时先按「大小」排最省事。
  • 筛选：「全部建议 / 保留（手工）/ 建议保留 / 待确认 / 不用保住」下拉，配合「只看新增」和目录切换，先把范围缩小再动手。

五、AI 说明（「AI 说明：这是个什么包」这一列）

  • 能分析什么：只看包名、大小、时间和路径就能判断绝大多数包；压缩文件也能分析——zip、rar、7z、tar、gz、iso、whl、crx、jar 这类包会先只读取一份内部文件清单（最多 24 个名字，不解压、不写磁盘），再交给 AI，所以「WeChatSetup.zip」这种只有英文文件名的包也能说清是什么。
  • 哪些项目要分析：点右侧「AI 分析」时，有勾选就只分析勾选的；一个都没勾就分析所有还缺说明的项目。设置里的「立即 AI 分析」是同一个意思。
  • 为什么一点就完成：不是有时限，而是命中缓存。分析结果按「文件名 + 大小 + 修改时间」存档，文件没变就直接复用，不会再去请求 AI，所以看起来是秒完成的。
  • 会告诉你多久前分析过：左侧信息条会写「这 N 项 X 分钟前分析过，文件没变，不用再分析」；每个单元格里也有「X 分钟前」的小字，鼠标悬停能看到具体时间和所用的模型。
  • 想重做：按住 Shift 点「AI 分析」会忽略缓存重新问一遍。你动过的那几格默认跳过；只勾选它一个再点「AI 分析」，会先问一句是否继续，确认后新的一句「AI：…」加在你写的内容下面、你写的字不动，并深挖子目录（目录里各层文件和压缩包里的更多条目一起交给 AI）。文件本身变了（大小或修改时间不同）会自动当成新包重新分析。
  • 不会自己乱跑：只有你点「AI 分析」「立即 AI 分析」「智能搜索」，或者打开了「启动时自动分析」时才会调用接口；那个开关默认是关的。扫描本身不调用 AI——判断「这个目录是不是多个包的集合」默认走本地规则 + 以前缓存的结论；想在扫描时也让 AI 判断，去设置里勾「扫描时用 AI 判断目录是否该展开」（默认关闭）。
  • 没有 Key 也能用：没配置 Key 时「AI 说明」列显示「--」，其余功能（清理建议、保留、转移、回收站、改说明）照常工作。

六、智能搜索

  • 关键词过滤：在搜索框里直接输入就实时过滤，名称、路径、类型、AI 说明、你的说明都参与匹配。
  • 自然语言搜索：输入一整句，比如「上次那个装 CUDA 的安装包」，按 Enter 或点「智能搜索」，会先用关键词在本地匹配，再让 DeepSeek 把这句话扩成语义相近的条件；搜索框旁的提示会说明这次是「关键词 + AI 语义」还是「只有关键词」。
  • 清空搜索：把搜索框清空就回到完整列表。

七、勾选后的批量操作（按钮永远固定在工具栏右侧）

  • 标为保留：这个包永久留用，不再出现在清理建议里，徽章变成「保留（手工）」。
  • 取消保留：取消手工保留，重新按磁盘实际情况评估建议；徽章上的小 ✕ 就是同一个功能。
  • 设为忽略：写进本机忽略名单，以后扫描直接跳过（不删除文件）；想让它回来，去设置 → 忽略名单点「恢复」，再点「重新扫描」。
  • 转移所选…：选目标目录（可以直接写绝对路径，也可以点「浏览…」，最近用过的目录会列出来）；同名目标不覆盖，成功转移的项目从列表里消失。
  • 移到回收站：走 Windows 回收站，误点了还能还原；只对扫描范围内的项目生效，范围外的一律拒绝。

八、左侧信息条

  • 工具栏左边固定显示「已选 N 项」，后面的信息条会实时播报：加载与重新扫描的进度和结果、AI 分析进行到哪一步，以及保留、取消保留、忽略、转移、移到回收站、说明保存的结果。
  • 带跳动圆点表示正在忙，静态圆点表示已完成，红色表示出错（例如 AI 调用失败的原因会直接写在这里）。

九、改这一格的说明（改完就是你说了算）

  • 为什么要改：AI 只看文件名、大小、时间和压缩包里的清单，名字含糊的包（比如 setup_v2.exe）可能说错、可能只说一半。
  • 怎么进去：双击这一格，或者用键盘 Tab 走到这一格按 Enter（F2 也行），也可以右键 →「改这一格的说明」；单击不会进编辑。保存就按 Enter（Ctrl+Enter 也一样），要换行用 Shift+Enter，点别处也会保存，Esc 放弃。
  • 框里那句「AI：…」是素材：留着它保存＝你接受了它的内容，保存时把这段并入你的话（只去掉「AI：」这个来源标记）；删掉它保存＝你不要那部分；全删干净保存＝这一格空着，AI 不会再写回来。
  • 动过之后就归你：只要这一格被你改过（改了 AI 那句、自己加了字、或者全删干净），它就不再单独显示「AI：」那一行，显示的全是你留下的内容；AI 原来那句也不再算这一格的内容（搜索、排序、智能搜索都不再匹配它）。
  • 还是想让 AI 单独说一遍：勾上它单独点「AI 分析」（或按住 Shift 点），会先问一句；确认后新的一句「AI：…」加在你写的内容下面，你写的字一个都不动——只能你自己删。
  • 批量分析会跳过你动过的：点「AI 分析」时，你动过的项目默认不分析，信息条会写「另 N 项你自己动过，已跳过」。被跳过的是哪几格，在 设置 → 忽略名单 →「AI 分析」那个标签里全都列着（名称、理由、你的话），想让哪一个重新说一遍就点它右边的「让 AI 重新分析」。
  • 正在编辑的那一格不会被冲掉：你在框里打字时，AI 分析的结果不会重绘这一格，保存完再看。
  • 最多 400 字，可以多行。你写的内容存在本机 user_notes.json，哪些格子已经归你的记录在 ai_hidden.json，都随扫描一直保留，也会被搜索框匹配到。

十、右键菜单

  • 任意一行右键可选：AI 分析、改这一格的说明、标为保留、取消保留、忽略、打开所在目录、转移到其他目录、移到回收站。
  • 多选后右键，菜单里会显示「N 项」，除「改说明」和「打开目录」（只能单行用）之外都可以批量操作。

十一、设置里另外三页

  • 模型设置：填 DeepSeek 的 API Key、API 地址、模型名；「测试连接」用当前填写的内容发一次请求验证；「启动时自动分析缺少说明的项目」默认关闭；「扫描时用 AI 判断目录是否该展开」默认也关闭（关着扫描纯本地、不联网）；「立即 AI 分析」先保存再对缺少说明的项目跑一遍；「清除 Key」把本机环境变量与残留一起清掉。Key 只存本机用户环境变量 DEEPSEEK_API_KEY（加密保护），不写进配置文件、不进 Git。
  • 忽略名单：两个标签。①「搜索目录」＝扫描时会跳过的名字，点「恢复」撤销，恢复后要重新扫描才会回到列表；②「AI 分析」＝被 AI 分析跳过的那几格（你改写过的、或把「AI：…」那句删掉的），每行写着名称、理由、「你写的话」和路径，右边「让 AI 重新分析」只对这一个再问一次 AI，新的「AI：…」加在你的话下面、你写的字一个不动。两个标签上都带数量。
  • 外观与主题：跟随系统 / 浅色 / 深色三选一；右上角的 ☾ / ☀ 按钮可以快速切换，选择会被记住。

十二、标题栏的「自动问答」

  • 它在哪：窗口最上面那一行中间那个圆角输入框，不用先切到表格里找搜索框。
  • 怎么用：输入一句自然语言（例如「怎么把某个包永久保留」「扫描为什么这么快」），按 Enter，它会把这个问题连同应用内的功能说明 + README 全文一起发给 DeepSeek，答案弹在对话框里。问句下面会写明这次用掉多少 token、耗时几秒。
  • 想按关键词过滤表格：那是「搜索」，不是问答案——用表格上方那个搜索框（或工具栏的「智能搜索」按钮）；在问答对话框里点「用这句搜表格」，也可以把刚才那句话直接丢给搜索去过滤。
  • 没配置 Key 时：按 Enter 不会提交，鼠标悬停会提示「要使用自动问答，请先到「设置」中配置 LLM KEY」；到设置 → 模型设置里填好 Key 并保存，回来立刻就能用。

十三、命令行（CLI，给 GPT / dsh 这类外部工具读数据用）

  • 两种调用方式：源码运行 python cli.py list；打包好的 EXE 运行 下载包管家智能搜索版-v22.exe --cli list --out out.json。窗口版 EXE 没有控制台，建议一律加 --out 把 JSON 写进文件。
  • 子命令：status（版本 / 上次扫描时间 / 是否配置 Key）、groups（标签、目录、条目数）、scan [--force]（纯本地扫描一次）、list（列出条目，可加 --group / --query / --recommendation / --sort / --limit）、search 一句话（纯本地关键词召回）、describe 路径（看单个条目）。
  • 不会花钱：CLI 只做本地扫描与关键词匹配，不会替你调用 DeepSeek。
  • 输出：UTF-8 的 JSON（加 --pretty 变成多行缩进）；出错时 ok 为 false、退出码非 0。

十四、功能问答：把功能说明全文交给 AI

  • 在哪问：两个地方都能问——① 窗口标题栏中间那个「自动问答」框，问一句按 Enter，答案直接弹出来；② 就是这一页顶上的输入框，按 Enter（或点「提问」），答案显示在下面。
  • 它凭什么答：把这一整页「功能说明」和 README 的全文（约 1.4 万字）一次性放进提示里发给 DeepSeek，让它只按这份资料回答——没有向量库、没有索引文件、不用额外安装或部署任何东西，装着就能用。资料里没写的，它会直说「功能说明里没写」，不会瞎编。
  • 要不要 Key：要。没配 LLM KEY 时输入框是锁定状态，悬停会提示先去「设置 → 模型设置」填 Key，点「提问」也不会发请求。
  • 花多少钱：每次提问大约一万多个 token 的输入。按 deepseek-flash 现价（高峰输入 $0.3 / 百万 token）算，一次约 0.02 元；同一份资料命中缓存后近乎免费。答案下面会写明这次实际用掉的 token 与耗时。
  • 它不做什么：不改你的文件、不扫盘、不读你的下载包清单，只回答软件怎么用。要按内容找包，用标题行那个「自动问答」或工具栏的「智能搜索」。

十五、数据与安全

  • 所有数据都在本机：扫描快照、AI 说明缓存、你改过的说明、忽略名单、保留标记、设置文件。
  • 模型配置怎么存：常用模型放在本机的 models.json 里，列表和「当前默认」分开存、用内部 ID 对应；每个模型各自存自己的服务商、接口地址、型号、接口类型与 Key。Key 用 Windows 的 DPAPI 加密后保存（只有本机当前用户能解开），界面上永远只显示尾号，模型配置文件里不会出现明文 Key。
  • 软件不运行、不解压、不上传你的任何文件；唯一的外发内容是你主动触发的 AI 分析请求（包名 + 可选的文件清单）和智能搜索的那一句话。
  • 删除只走 Windows 回收站，转移只是普通的文件移动，都不会静默覆盖同名文件。

模型

每个模型单独保存。「保存」只存这一个模型、默认模型不变；「设置为默认」会把这上面最新填写的内容一起存下来，并马上切成默认（AI 分析、智能搜索立刻用它）。改字段、刷新列表都不会自己保存，也不会自己联网。

名字旁边的圆点＝必要字段齐不齐：绿色表示服务商、接口地址、型号、Key 都填好了；灰色表示跑不起来。
只写服务商给的地址前缀，程序会按接口类型补上 /chat/completions、/responses 或 /messages。
可以从预置型号里挑，也可以直接改成服务商支持的任意型号；改过的型号原样保存，升级不会被预置值覆盖。
验证结果只显示在这个窗口里；某个模型验证失败不影响其他模型，也不会把这份草稿存下来。
